# Tests

- `unit/`: deterministic component tests.
- `integration/`: boundaries between the gateway, replay, storage, and statistics.
- `validity/`: simulated-null, coverage, false-alarm, and reference checks.
- `ci/`: offline candidate-versus-production release-gate checks.
- `e2e/`: service, canary, rollback, and alert paths.
- `fixtures/`: small tracked inputs only.
